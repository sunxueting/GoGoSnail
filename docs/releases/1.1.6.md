# 1.1.6 免广告复活与入口统计候选版

在 1.1.5 的中文界面、全服排行榜、长屏适配与安全复活基础上，将结算复活入口显示为视频图标和“看广告复活”。点击直接满血恢复原对局并显示“本次免广告／已为您满血复活！”，不调用广告 SDK，不等待统计响应，保留分数和每局一次限制。

通过 `wx.reportEvent` 上报开局、曝光、点击和成功事件；曝光与点击每局去重，统计失败不影响发奖。既有场景的 `GameLogic.CheckContinueGame` 和兼容桥接入口均进入同一领取流程。后台使用去重玩家数计算点击占比，事件字段、验收与指标见[免广告复活统计](../免广告复活统计.md)。

这是 1.1.6 本地候选修改。此前成功上传的是 1.1.5；本次不等同于 1.1.6 已上传、已提审或上线。微信统计后台事件配置、真机入库和真实点击率仍待确认。隐私、网络类型/备案、其余排行榜真机验证等原有提审事项仍需完成。

## 本地检查（2026-10-29）

构建、`test:revive`、`test`、`test:layout`、`test:release`、`test:ranking-ui`、`test:performance` 通过。实际 Cocos 触摸覆盖四种视口，满血恢复、保留得分、一次限制、统计异常及过期点击均通过；合成三玩家数据验证 UV 与 PV 分母不同，不能把这些测试比例当成运营数据。截图人工检查已确认视频图标、中文标题和免广告提示正确显示。静止首页没有同步最高分读取或静态坐标逐帧换算。

## 结算页手机尺寸适配修复

旧结算遮罩高度固定为 2000 设计单位，长屏下部露出未变暗的背景；部分控件依赖旧版固定坐标，游戏血量显示还会透在结算控件后方。现按实际可见宽高等比覆盖遮罩，补偿旧场景父节点缩放，背景保持比例裁切而不拉伸。结算内容按可用屏幕高度分行布局，避开微信胶囊及底部安全区，个人纪录文字与数字居中对齐；新纪录合入同一行说明，避免额外提示挤占按钮区域。结算隐藏游戏血量与进度，复活后恢复。成绩同步提示仅在结算时显示，返回首页后隐藏。

本地 `test:layout` 增加七种尺寸，包含与用户截图相同比例的 393×911 长屏、320×568 短屏及 768×1024 平板，验证遮罩四角实际像素变暗、屏幕内边界、各行无重叠、八位分数及动态尺寸变化。实际按钮触摸、每局一次复活、重开、发布界面与性能回归通过。本地测试不等同于用户手机确认。

同时修复重建时删除整个输出目录的问题：微信编译进程可能仍以该目录为工作目录，导致 `ENOENT: uv_cwd`。现在先在独立暂存目录生成完整构建，再原子更新有变化的文件并清除过期文件，保留已有目录。实际持有 assets 工作目录跨重建验证通过，根目录及 assets/libs/src 的 inode 保持不变。

微信原生模拟器已确认自然失败后的结算遮罩覆盖到底、个人纪录对齐和返回首页可用。官方 CLI 已为此修复版生成新的 1.1.6 真机预览码，总包 5,581,646 字节；二维码及信息文件仅保存在被 Git 忽略的 artifacts 中。开发版本仍为此前上传的 1.1.5，尚未提交新的审核。用户手机尚待扫描新码复核。
