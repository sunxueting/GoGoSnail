## 改动

主页以原生中文文本替换旧英文标题和关键操作图中的文字；设置页显示正式名称与版本。分享调用、工程配置和网页标题共用 ReleaseConfig。版权人名与音乐署名保留原文。

增加 8+ 适龄说明与健康游戏提示。首页控件按可见区域布局，提示页遮罩覆盖全屏并阻止底层按钮误触。网页验证采用与微信构建一致的系统字体。

本机纪录资源未就绪时展示加载状态，准备完成后显示纪录和可选资料授权；关闭时取消待展示状态，长时间未完成可点击重试。修正删除检查对旧回调对象的取值。

## 检查和限制

构建、实际本地触摸玩法、隐私模拟、四屏背景/复活，以及发布显示和真实资源延迟检查均已通过。检查产生的截图和 JSON 位于本机 artifacts/release-1.1.4，不提交包含个人信息的后台截图或凭据。

开发者工具 CLI 已确认登录和上传成功；本轮工具窗口控制连接超时，未取得新一轮模拟器或手机实屏验收。不可把上传成功写成真机检查通过。

本地及模拟 API 检查不等于微信真机验收。仍需微信端核对最终标题、中文按钮、分享卡片和资料授权；后台当前头像、简介、类目、完整隐私协议、适用备案和资质分别核实。未确认这些项目全部通过，未承诺再次提审一定通过。
