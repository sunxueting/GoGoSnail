# 1.1.5 全服排行榜候选版

2026-10-29，用户选择微信云开发。代码已加入按玩家历史最高分排序的榜单、本人名次、同分并列、分页、可选头像昵称公开、撤下资料及退出删除。主页在配置云环境后显示全服最高分，个人结算仍明确标注个人纪录。保留本机纪录与本机头像昵称授权；核心玩法无需成功连接排行榜。

前端环境 ID 配置仍为空，游戏默认仍是本机模式；全服入口在完成云端配置和验证后启用。2026-10-29 用户已开通 cloud1 微信体验环境，官方 CLI 已确认环境并成功部署 snailLeaderboard（5 文件、15.3 KB，云端安装依赖）。数据库集合、权限、索引和函数超时配置尚未完成；尚未上传 1.1.5、尚未提审。原 1.1.4 上传包未改变。

服务端以微信注入的身份识别玩家、校验 AppID，以事务保持最高分；分数必须属于当前有效对局。头像昵称单独同意后提交，检查完成且通过才公开。数据库客户端读写应全部关闭，部署清单见 [微信云排行榜部署](../微信云排行榜部署.md)。

本地测试使用实际游戏场景、模拟微信传输和内存事务数据库，覆盖多用户排序、并列、低分及并发提交、翻页、对局归属/有效期、参加确认、拒绝公开、撤销权限、资料撤下、退出删除及断网。截图为合成测试数据，不能据此声明云数据库、微信内容检查或真机已验证。
