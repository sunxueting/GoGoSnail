# 1.1.15 按红框左移蜗牛主体

上版只调整了纵向，横向仍偏中。本版按用户红框将蜗牛可见主体左移到屏宽约 13%—59% 的区域，保留原有三倍大小和纵向位置，不移动标题及副标题。

该 PNG 包含左侧速度线和透明区域，不能用整张图片中心代表蜗牛主体中心。读取原始 1536×1024 PNG，以 alpha≥220 的最大连通区域确定主体边界 x=440..1381、y=104..913。位置调整后，主体横向边界约为屏宽 12.73% 和 58.73%，符合用户红框约 13%—59% 的范围。图片画布允许部分延伸出左边界，主体完整，部分速度线由屏幕裁切。

本地五种尺寸验证主体横向位置、标题居中、图片大小及比例、文字层级、分数间距和触摸。代表性长屏验证主体也处于红框纵向区域。真实渲染对比中标题描边 1717/1721、副标题 715/728 采样像素保持一致，符合 98% 以上阈值，结合显式层级检查验证文字位于图片上方。
