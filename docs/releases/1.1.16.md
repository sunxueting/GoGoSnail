# 1.1.16 蜗牛脚底与标题字形底部对齐

用户确认“蜗牛图片的底部跟‘蜗牛’两个字底部齐平”的预览并要求应用至游戏。本版上移既有蜗牛素材，不更换美术，不裁掉脚部；保留原有三倍大小、主体横向约 13%—59% 屏宽位置、标题居中和更高文字绘制层级。标题、副标题及其他按钮位置不变。

根据固定素材 1536×1024 中主体下边界 row=914 和当前标题字号/描边的视觉底部计算蜗牛坐标。对齐主体脚底而非含透明区域的 PNG 画布底边，继续按屏宽等比适配。

本地真实渲染校验：读取隐藏图片时的标题描边像素底部，与显示素材时的主体脚底比较。390×844 差约 0.16 像素，430×932 差约 0.53，320×568 差约 0，375×667 差约 0.77，768×1024 差约 0.60。五屏标题与副标题可读性、图片比例/横向位置、按钮边界、提示页真实触摸、分享、平板开局及游戏中隐藏通过。首页性能检查保持按需布局。
