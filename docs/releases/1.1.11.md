# 1.1.11 首页标题居中与蜗牛放大

标题不再为左侧蜗牛偏移：水平中心与屏幕中心一致，文字容器占可见宽度 88%，字号随宽度调整。在微信中读取原生胶囊底部，整块标题至少留出 12 个屏幕像素间距。

复用 1.1.10 的独立透明冲刺蜗牛素材，不重新生成图片。蜗牛移至副标题下方、最高分上方，保持 3:2 原图比例；画布目标宽度为屏幕宽度 42%，扣除透明边缘后可见主体约占屏宽三分之一。上下分别为副标题及最高分预留间距，空间不足时优先按可用高度收缩，避免遮挡文字。

屏幕高宽比小于 1.6 时使用紧凑布局，重新排列分数、开始和底部控件，缩小开始图形并独立定位“开始游戏”文字。换回长屏自动恢复正常排列。所有尺寸与坐标仅在视口、界面状态或资源就绪变化时更新。

验证：320×568、375×667、390×844、430×932、768×1024 的标题/副标题/蜗牛居中，图片比例与目标大小、文字无重叠、边界、适龄/健康提示及实际分享调用；393×911 下模拟微信胶囊避让；平板开始按钮通过实际触摸进入游戏，主页图片随游戏隐藏。首页性能采样未增加空闲坐标转换或最高分存储读取。以上为独立桌面浏览器验证，微信手机效果仍待确认。

构建版本 1.1.11，官方 CLI 生成手机预览，未重新提审或发布；后台注册名称与资质资料未修改。
