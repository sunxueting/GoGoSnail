# 1.1.9 游戏暂停

游戏右上角增加圆形双竖线暂停按钮。使用微信窗口安全区和胶囊菜单位置，将按钮放在胶囊下方，触摸区至少 44×44 屏幕像素。仅在资源就绪、教程关闭、玩家存活的游玩阶段显示，死亡动画和结算阶段不显示。

暂停后显示“游戏已暂停”和“继续游戏”。暂停 Cocos director 的调度、动作和物理更新，保留渲染与输入分发；角色、镜头、生命值、无敌时间及得分计时冻结。记录并暂停原本正在播放的 AudioSource，继续时恢复这些声音。继续按钮恢复同一对局，不重置分数、复活次数或重新创建云端对局。

触摸在按钮/面板内拦截，玩家跳跃入口同时检查暂停状态，防止暂停、继续或键盘输入误触发跳跃。切入后台时自动暂停，返回后仍需手动继续；暂停时改变窗口大小会更新遮罩与控件。节点销毁清理监听及定时器，避免场景切换后遗留引擎暂停状态。

本地 `test:pause` 使用实际 Cocos 场景和触屏操作，覆盖 393×911、320×568、430×932、768×1024 四种尺寸、胶囊安全区、真实四角遮罩像素、继续文字可见、圆周运动/腾空物理冻结恢复、游戏计时和生命值不变、声音暂停、无额外开局/跳跃、暂停时缩放、后台/前台事件、死亡和返回首页。玩法及性能回归通过；静止首页未增加逐帧坐标变换。

这些为独立桌面浏览器检查，生命周期与微信胶囊为模拟数据，不替代微信真机确认。版本包含 1.1.8 的死亡首帧遮罩与成绩同步修复，原有旧成绩补传和上线资料限制仍适用。本版未改动云函数或生产分数，未重新提审。
