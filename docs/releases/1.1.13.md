# 1.1.13 标题居中、左侧三倍蜗牛在文字下层

用户确认“标题左侧，层级在文字下，不遮字”。本版将标题文字本身水平中心对齐屏幕中心，容器宽 88%，并将左侧蜗牛在用户截图原始 240×160 的基础上将宽、高各放大 3 倍至 720×480（以 960 可见宽度为基准，其他尺寸等比换算）。这不是继续将 1.1.12 放大三倍。

蜗牛中心位于屏宽 37.5%，画布占屏宽 75%，保持完整宽度和 3:2 比例，使用既有透明素材。图片上移，使副标题位于图片下方；标题前景与图片底部区域可以相交，采用用户要求的层级关系：图片 zIndex=0，标题及副标题 zIndex=20。标题深色描边宽度由 4 增至 6；文字本身保持白色。标题继续避开微信原生胶囊。

五种尺寸验证标题本身居中、图片位于左侧、相对截图的三倍大小、比例与边界、副标题/分数间距、真实提示页操作及分享，平板开始按钮真实触摸与游戏中图片隐藏通过。新增真实像素检查：对比显示及隐藏蜗牛时的标题描边，1721 个采样像素中 1719 个保持一致，证实标题绘制于重叠图片之上。0.001 场景单位的边界容差只用于浮点运算误差。首页性能验证仍为按需布局。

官方 CLI 已生成 1.1.13 手机预览，尚未重新提审或发布；桌面浏览器检查不代替手机确认。后台名称与资质资料未修改。
