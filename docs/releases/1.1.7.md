# 1.1.7 结算背景与地图连续生成修复

用户手机反馈结算页下方背景未完整覆盖、游戏后续没有圆圈可跳。本版在 1.1.6 基础上处理真实加载竞态和接缝触发遗漏，并增加窗口适配与结算遮罩防护。

## 问题与修改

- 旧代码在最后一行关卡目录回调完成时就标记全部就绪。注入慢加载后，最后一行已完成，LV1 等目录仍为空；重复目录也会留下数组空位。现在按所有配置目录和八个必需预制体共同判断就绪，相同目录共用资源。失败自动重试两次，持续失败显示可点击的重试提示。
- 旧地图只在镜头碰撞进入接缝时生成下一段。现在在镜头靠近时预加载，并通过位置检查补救长帧跳过接缝；每个接缝先锁定再生成，同帧最多补八段，避免重复触发或无限循环。
- 背景旧代码可能在图片未加载时按分数切换，写入空帧；旧淡出还会将整张底图变透明。现在等图片和配置全部就绪才切换，缺失资源时保留原图，新图在不透明底图上渐入，快速跨阈值取消过期切换。
- 结算遮罩不再依赖旧图的裁切和透明边缘，直接按可见区域绘制并补偿父节点缩放；微信窗口大小使用实际 windowWidth/windowHeight 和 pixelRatio，窗口变化时更新适配器。

## 验证与边界

2026-10-29 本地构建和游戏流程、头像隐私授权、复活统计、发布界面、排行榜 UI、性能及尺寸适配检查通过。尺寸检查覆盖七种结算视口；使用实际图像边缘像素检查背景和遮罩覆盖。

新增 `npm run test:progression`：注入乱序加载、一次失败、持续失败、背景慢加载及连续分数变化，验证未就绪不进入对局、失败可真实触摸重试、重复目录仅请求一次、底图始终存在。实际 Cocos 场景完成八次触屏发射和物理落圈（使用无敌状态隔离障碍影响）。另进行六十次合成镜头快速跳跃，本次生成 170 段，覆盖全部难度，始终有后续圆圈，同一接缝重复碰撞仅生成一次。随机地图导致生成总段数随运行变化，测试断言连续性而非固定段数。

窗口尺寸与像素比检查使用合成微信数据，网页测试不等同于手机认证。微信开发者工具已编译并通过官方 CLI 生成 1.1.7 预览码，总包 5,585,280 字节（主包 1,728,569 字节）。二维码和报告保存在被忽略的 artifacts 目录，未作为源码提交。

用户手机仍需扫描本次新码，核对设置页为 1.1.7，并复测结算页、复活后继续和长距离跳跃。此前 1.1.5 的开发版上传状态没有因生成预览码而改变；本版尚未重新提审。隐私指引、联网资料和统计后台验收等原有上线事项仍待完成。
